# 🧠 SmartNotes Ultra

A modern, responsive and lightweight notes web application built with HTML, CSS, and JavaScript.  
It features dark/light mode sync, localStorage saving, and a clean SaaS-style UI inspired by Notion and Apple Notes.

---

## 🚀 Features

- 📝 Create and manage notes
- 💾 Save notes in browser (localStorage)
- 🌙 Dark / ☀️ Light mode (sync across all pages)
- 🧭 Multi-page website (Home / Notes / About)
- 🎨 Modern SaaS UI design (glassmorphism style)
- ⚡ Fast, lightweight, no frameworks
- 📱 Fully responsive design

---


---

## 🛠️ Tech Stack

- HTML5
- CSS3 (CSS Variables + Glassmorphism)
- Vanilla JavaScript (ES6)
- LocalStorage API

## ⚙️ How to Run

1. Download project
2. Open folder
3. Run `index.html` in browser
4. Done ✅

No installation required.

## 🌙 Dark / Light Mode

- Click theme button 🌙
- Theme changes instantly
- Saved automatically in localStorage
- Works across all pages

## 🧠 Notes System

Notes are stored like this:

```js
{
  title: "Example title",
  tag: "#work",
  content: "Your note text here"
}
```
